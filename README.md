Docker-Based Web Application Deployment

Project Overview

This is a beginner-friendly DevOps project that deploys a simple website using Docker and Nginx.

Objective

To learn how to build a Docker image and run a web application inside a Docker container.

Tools Used

* Docker
* Docker Desktop
* Ubuntu (WSL)
* Nginx
* Git
* GitHub
* HTML

Project Files

* Dockerfile – Builds the Docker image using Nginx.
* index.html – Contains the website content.

Steps Performed

1. Installed Docker Desktop and configured Ubuntu using WSL.
2. Created a simple HTML webpage.
3. Created a Dockerfile using the Nginx Alpine image.
4. Built the Docker image.
5. Ran the website in a Docker container using port 8080.
6. Verified the website at http://localhost:8080.
7. Uploaded the project files to GitHub.

Output

The website displays:

Hello from Docker!

My first DevOps project is running.

Conclusion

This project demonstrates basic containerization and web application deployment using Docker and Nginx.
